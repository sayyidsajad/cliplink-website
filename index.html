Copy a file.
Paste a link.

ClipLink turns Finder ⌘C into a private, expiring download URL — automatically.

Download for macOS View source on GitHub
latest release · macOS 13+ · free & open source
1. Copy any file in Finder → menu-bar icon lights up and uploads it
2. Your clipboard → https://api.cliplink.workers.dev/s/token
3. Paste it anywhere. The link self-destructs after 24 hours.

What it does

⇧ Zero friction

No drag-and-drop, no upload forms. The act of copying a file is the upload.

⏳ Expiring links

Every link dies after 24 hours and its bytes are deleted from storage. No permanent leaks.

🛑 Instant revoke

Every share has a secret revoke token. Delete from the menu-bar history — access ends immediately.

🔒 Privacy blocklist

Key files (id_rsa, .ssh/*, .env…) are never uploaded. Patterns are yours to edit.

🙈 No accounts, no tracking

Uploads are anonymous. Install IDs exist solely for rate limiting and never authenticate anything.

🧾Server-enforced limits

Size, rate, and storage budgets live server-side; the app simply adapts to what the server permits.

Installing

  1. Download ClipLink.dmg above and drag ClipLink into Applications.
  2. First launch: right-click the app → Open → Open. Because it is ad-hoc signed (no paid Apple certificate), macOS shows this prompt exactly once.
  3. In the menu-bar clipboard icon, enable monitoring — done.
Plain-failure behaviour: if an upload doesn't succeed, your clipboard is left exactly as it was. The link replaces the clipboard only after the file is safely stored.

Trust & transparency

  • Nothing is permanent. Links expire in 24 h and the stored object is deleted right after by a cleanup job (verify in source).
  • Download URLs are unguessable — random tokens, no look-alike characters.
  • Storage objects are private. Downloads are brokered by the server through short-lived signed URLs that only the server ever mints (verify in source).
  • Storage is budget-capped server-side: usage is enforced strictly below the free tier, oldest files evicted first — the service can never silently hold your data forever, and no one can ever be surprised by a bill.
  • Revoke anything instantly. Share pages answer with a friendly “revoked” state, then 404 after retention.
  • The whole backend is ~2 files of JavaScript — auditable in five minutes: read them here.
  • Found an issue? See our security policy — reports welcome and answered quickly.
